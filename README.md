# Python-Programming-Lab-Record
Lab exercises and assignments from Semester 1 : Python Programming course at CHRIST (Deemed to be University).

This repository contains the official record of **lab exercises and assignments** completed for the **Python Programming** course during **Semester I** at **CHRIST (Deemed to be University)**.

The collection is organized into a series of Jupyter Notebooks, demonstrating practical implementation of foundational and intermediate Python concepts, data structures, and basic data science tools.

-----

## Lab Index

The repository contains 10 sequential lab notebooks (`.ipynb`), each focusing on key topics covered throughout the semester.

| File | Primary Topic | Key Concepts Covered |
| :--- | :--- | :--- |
| **`LAB_01.ipynb`** | Introduction & Basic Operations | `print` statement, Variable assignment, Arithmetic operations, Solving algebraic expressions. |
| **`LAB_02.ipynb`** | Control Flow | `if/elif/else` statements, Checking Odd/Even, Multiples of a number, Voting Eligibility, **Body Mass Index (BMI) Calculator**. |
| **`LAB_03.ipynb`** | Strings | String Slicing, Palindrome check, String comparison (Equal, Less Than, Greater Than), Counting character occurrences. |
| **`LAB_04.ipynb`** | Lists | List creation, essential list methods (`insert()`, `remove()`, `append()`, `pop()`, `clear()`), Sorting, Finding Min/Max elements. |
| **`LAB_05.ipynb`** | Tuples and Sets | Tuple creation, and core **Set Operations** (Union, Intersection, Set Difference). |
| **`LAB_06.ipynb`** | Dictionaries | Dictionary creation from user input, Renaming keys, Extracting elements based on non-numeric values. |
| **`LAB_07.ipynb`** | Comprehensions | **List Comprehension** (e.g., generating palindromes), **Dictionary Comprehension** (e.g., filtering words by Fibonacci length). |
| **`LAB_08.ipynb`** | Functions | Defining and calling functions, Calculating **Fibonacci Series**, Merging Dictionaries, Generating String Permutations, Custom Sorting using a `key` function. |
| **`LAB_09.ipynb`** | NumPy | Creating and manipulating multi-dimensional **NumPy Arrays**, Array arrangement (sorting/reshaping), Generating random arrays. |
| **`LAB_10.ipynb`** | Pandas & Visualization | Creating Pandas **Series** and **DataFrames**, Calculating statistical measures (e.g., Mean), Finding **Correlation** among attributes, Data Visualization (Heatmaps). |
